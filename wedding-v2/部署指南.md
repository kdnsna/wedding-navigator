# 甜囍手册 · 部署指南

给你（部署者/开发者）：把这套多婚礼请柬系统跑起来，全程约 20 分钟，**不需要服务器**，云函数只有一个（getPhotos，第 4 步一键部署）。

## 1. 导入项目

微信开发者工具 → 导入项目 → 选择本目录（`wedding-v2/`）。AppID 已在 `project.config.json` 里配好；换成你自己的小程序就改 `appid` 字段。

## 2. 开通云开发（核心一步）

1. 开发者工具顶部点「**云开发**」→ 开通（免费档够用）
2. 复制环境 ID（形如 `wedding-xxxxxx`）
3. 填进 `config/app.js` 的 `cloudEnv: ''` 引号里

## 3. 建数据库集合（3 个）

云开发控制台 → 数据库，逐个新建并设置权限：

| 集合名 | 权限 |
| --- | --- |
| `weddings` | 所有用户可读，仅创建者可写 |
| `blessings` | 所有用户可读，仅创建者可写 |
| `rsvps` | 所有用户可读，仅创建者可写 |

> 「仅创建者可写」依靠记录自带的 `_openid` 字段自动校验主人身份——业务读写因此零云函数（唯一的 getPhotos 只为绕开免费版存储 ACL）。

## 4. 部署照片云函数

免费版云存储权限固定为「仅创建者可读写」且控制台不可改（改 ACL 需升级付费版），所以照片读取走云函数换临时链接：

```bash
/Applications/wechatwebdevtools.app/Contents/MacOS/cli cloud functions deploy \
  --project <本目录> -e <环境ID> -n getPhotos
```

或在开发者工具里右键 `cloudfunctions/getPhotos` → 「上传并部署：云端安装依赖」。

> 不需要改存储权限，保持默认「仅创建者可读写」即可——照片反而更私密。

## 5. 验证

- 双击 `脚本/预览.command` → 微信扫码 → 走一遍：创建婚礼 → 填信息 → 传两张照片 → 点「把请柬分享给宾客」发到文件传输助手 → 从卡片进入 → 提交一条回执和祝福 → 回主人台确认能看到
- 模拟器里 `wx.chooseLocation` 可用，但坐标选择建议真机验证一次

## 6. 上线

1. 双击 `脚本/上传.command` 上传版本
2. [mp.weixin.qq.com](https://mp.weixin.qq.com) → 版本管理 → 提审（类目建议「生活服务 → 婚庆」）
3. 提审前在「设置 → 服务内容声明」完成用户隐私协议（涉及用户填写的文字与上传的图片）

## 常见问题

- **宾客看不到照片**：第 4 步存储权限没设
- **主人保存婚礼失败/编辑别人的婚礼失败**：第 3 步权限设错，必须是「仅创建者可写」
- **创建按钮点了没反应**：`cloudEnv` 没填或云环境未开通
- **免费额度**：照片存储与下载按量计费，婚纱照样片量级（每场 10 张 × 300KB）远低于免费档；火了再考虑升配
