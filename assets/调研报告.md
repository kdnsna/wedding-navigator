# 婚书/婚礼全流程导航产品调研报告

> 调研时间：2026年  
> 背景：主人2026年11月14日结婚，希望自己做婚书APP/小程序/网页，能导出个性化婚礼邀请函、婚礼卡片  
> **核心定位：婚礼全流程导航产品 = 婚书/请柬（门面）+ 路书/导航（核心）+ 场地信息 + 当天流程时间线**

## 一、项目定位与核心价值

### 1.1 现有产品的短板

主人说"现有工具（婚贝等）太low"，核心原因是：

| 痛点 | 现状 | 机会 |
|------|------|------|
| **功能割裂** | 请柬是请柬，导航是导航，流程是流程 | 一站式整合 |
| **路书缺失** | 婚贝等只有简单"点击导航到场地" | 接亲路线、宾客宾馆、多点串联 |
| **流程孤立** | 时间线只存在纸质/Excel里 | 数字化、可交互、可导航 |
| **导出鸡肋** | 只能生成H5链接，无法导出高质量图片 | 印刷级导出 |

### 1.3 婚礼场景的独特性

与普通导航不同，婚礼导航有以下特点：

| 特点 | 说明 | 实现价值 |
|------|------|----------|
| **多点串联** | 家→接亲酒店→婚礼大堂 | 接亲路线一图掌握 |
| **角色分众** | 新人/伴郎伴娘/宾客/父母 | 每人看到不同路线 |
| **时间强关联** | 每个地点有明确时间窗口 | "8:00从家出发" |
| **情感属性** | 不是冷冰冰的导航 | 设计感、温度感 |

### 5.3 地图功能实现代码示例

#### 高德地图 - 多点路线展示
```javascript
// 1. 初始化地图
const map = new AMap.Map('container', {
  zoom: 12,
  center: [116.397428, 39.90923]
});

// 2. 添加多个标记点
const locations = [
  { name: '家', lnglat: [116.3, 39.9], icon: '🏠' },
  { name: '接亲酒店', lnglat: [116.4, 39.95], icon: '🏨' },
  { name: '婚礼大堂', lnglat: [116.5, 40.0], icon: '⛪' }
];

locations.forEach(loc => {
  const marker = new AMap.Marker({
    position: loc.lnglat,
    title: loc.name,
    icon: new AMap.Icon({ size: [32, 32], image: loc.icon })
  });
  map.add(marker);
});

// 3. 驾车路线规划
AMap.plugin('AMap.Driving', () => {
  const driving = new AMap.Driving({
    map: map,
    panel: 'panel'
  });
  
  driving.search(
    locations[0].lnglat,  // 起点
    locations[1].lnglat,  // 终点
    { waypoints: [locations[1].lnglat] },  // 途经点
    (status, result) => {}
  );
});

// 4. 一键导航（唤起高德App）
function startNavigation(lng, lat, name) {
  const url = `https://uri.amap.com/navigation?to=${lng},${lat},${name}&mode=car&callnative=1`;
  window.location.href = url;
}
```

## 七、PDF/图片导出技术方案

### 7.1 成熟方案：html2canvas + jsPDF

```javascript
import html2canvas from 'html2canvas';
import jsPDF from 'jspdf';

async function exportPDF(elementId, fileName = '婚礼请柬.pdf') {
  const element = document.getElementById(elementId);
  
  // 1. HTML转Canvas
  const canvas = await html2canvas(element, {
    scale: 2,          // 清晰度
    useCORS: true,     // 跨域图片
    backgroundColor: '#ffffff'
  });
  
  // 2. Canvas转图片
  const imgData = canvas.toDataURL('image/jpeg', 1.0);
  
  // 3. 创建PDF（A4尺寸）
  const pdf = new jsPDF('p', 'mm', 'a4');
  pdf.addImage(imgData, 'JPEG', 0, 0, 210, 297);
  
  // 4. 下载
  pdf.save(fileName);
}

// 高清PNG导出
async function exportPNG(elementId) {
  const element = document.getElementById(elementId);
  const canvas = await html2canvas(element, { scale: 3 });
  const link = document.createElement('a');
  link.download = '婚礼请柬.png';
  link.href = canvas.toDataURL('image/png');
  link.click();
}
```

### 9.3 配置化数据结构

```typescript
// setting.json - 所有内容由这个文件驱动
interface WeddingConfig {
  // 新人信息
  couple: {
    groom: { name: string; photo?: string };
    bride: { name: string; photo?: string };
  };
  
  // 婚礼信息
  wedding: {
    date: string;      // "2026-11-14"
    time: string;      // "12:00"
    venue: string;     // 婚礼大堂名称
    address: string;   // 详细地址
  };
  
  // 场地（路书用）
  venues: {
    id: string;
    name: string;      // "接亲酒店"
    address: string;
    lnglat: [number, number];
    type: 'home' | 'hotel' | 'venue' | 'hotel_guest';
    time?: string;     // 到达时间
  }[];
  
  // 接亲路线
  route: {
    name: string;
    waypoints: string[];  // venue IDs
    estimatedDuration: number;  // 分钟
  };
  
  // 当天流程
  timeline: {
    time: string;
    title: string;
    venue?: string;     // venue ID
    assignee?: string; // 负责人
    notes?: string;
  }[];
  
  // 主题设置
  theme: 'modern' | 'traditional' | 'minimalist';
  colors: {
    primary: string;
    secondary: string;
  };
  
  // 功能开关
  features: {
    map: boolean;
    music: boolean;
    rsvp: boolean;
    blessing: boolean;
  };
```

## 十、市场机会与差异化方向

### 10.1 市场空白

| 维度 | 现有产品 | 机会 |
|------|----------|------|
| 婚书 | 婚贝等 | ✅ 已有，但设计老气 |
| **路书** | ❌ 无 | **✅ 核心差异化** |
| 多点导航 | ❌ 无 | **✅ 核心差异化** |
| 流程时间线 | 婚贝备婚清单 | ⚠️ 弱 |
| 高质量导出 | MAKA/Canva | ⚠️ 需自建 |

### 10.2 核心差异化

1. **婚礼路书导航**（首创）
   - 接亲路线可视化
   - 多点串联+时间关联
   - 角色分众视图

2. **中国传统婚书美学**
   - 经典文案库
   - 中式设计模板
   - 印刷级导出

3. **现代化UI/UX**
   - 简洁优雅的界面
   - 流畅动画
   - 移动端优先

### 10.3 下一步行动建议

1. **短期（婚礼前）**：

   - 选定参考模板
