### 1.3 角色识别机制

| 识别方式 | 实现方式 | 说明 |
|---------|---------|------|
| **首次访问** | 扫描小程序码/分享链接 | 自动识别身份 |
| **主人验证** | 输入主人手机号后4位 | 验证成功后显示编辑入口 |
| **数据关联** | openid + unionid | 微信生态唯一标识 |
| **权限存储** | 本地Storage + 云端 | 双端同步 |

// 婚书配置数据结构
interface InvitationConfig {
  id: string;
  wedding_id: string;
  
  // 模板配置
  template: 'traditional' | 'republican' | 'modern';
  colors: {
    primary: string;    // 主色
    secondary: string;  // 辅色
    text: string;       // 文字色
  };
  
  // 内容配置
  content: {
    title: string;           // 标题（如"两姓联姻"）
    main_text: string;      // 主文案
    sub_text?: string;      // 副文案
    story?: string;         // 爱情故事
  };
  
  // 新人信息
  couple: {
    groom: {
      name: string;
      phone?: string;
      photo?: string;
    };
    bride: {
      name: string;
      phone?: string;
      photo?: string;
    };
  };
  
  // 婚礼信息
  wedding: {
    date: string;        // "2026-11-14"
    time: string;         // "12:00"
    venue_name: string;   // 场地名称
    venue_address: string;// 场地地址
  };
  
  // 媒体配置
  media: {
    music?: {
      url: string;
      name: string;
    };
    cover_photos: string[];  // 封面照片列表
    story_photos?: string[]; // 爱情故事照片
  };
  
  // 功能开关
  features: {
    auto_play_music: boolean;
    show_countdown: boolean;
    show_rsvp: boolean;
    show_blessing: boolean;
  };
  
  // 时间戳
  created_at: number;
  updated_at: number;
}

#### 2.3.3 数据结构

```typescript
// 场地数据结构
interface Venue {
  id: string;
  wedding_id: string;
  
  name: string;              // 场地名称
  type: 'home' | 'hotel' | 'venue' | 'hotel_guest' | 'other';
  address: string;           // 详细地址
  coordinate: {
    latitude: number;        // 纬度
    longitude: number;        // 经度
  };
  
  arrival_time?: string;    // 到达时间 "10:30"
  departure_time?: string;   // 离开时间
  notes?: string;            // 场地说明
  
  // 住宿相关
  is_recommended_hotel?: boolean;  // 是否为推荐住宿
  distance_from_venue?: number;    // 距主场地距离(km)
  contact_phone?: string;          // 联系电话
  
  sort_order: number;        // 排序序号
  created_at: number;
  updated_at: number;
}

// 路线数据结构
interface Route {
  id: string;
  wedding_id: string;
  
  name: string;              // 路线名称（如"接亲路线"）
  type: 'pickup' | 'guest' | 'custom';
  waypoints: string[];       // 场地ID顺序
  
  // 路线统计
  total_distance?: number;   // 总距离(km)
  total_duration?: number;   // 总时长(分钟)
  
  created_at: number;
  updated_at: number;
}

// 路书配置
interface GuidebookConfig {
  id: string;
  wedding_id: string;
  
  venues: Venue[];           // 场地列表
  routes: Route[];           // 路线列表
  
  // 展示设置
  display_settings: {
    show_all_venues: boolean;
    default_route?: string;  // 默认展示的路线ID
    enable_nearby_hotels: boolean;
  };
}
```

#### 3.2.2 推荐方案：微信云开发 + 云数据库

   - 云函数自动扩缩容
   - 无需管理服务器

2. **微信生态深度集成**
   - 用户登录、支付直接对接微信
   - 消息推送方便
   - 小程序码生成便捷

   - 基础套餐免费
   - 按量付费，适合初期项目

4. **数据同步**
   - 云端实时同步
   - 支持多人协作

**数据库选型对比：**

| 数据库 | 适用场景 | 优点 | 缺点 |
|--------|---------|------|------|
| **云开发MongoDB** | 结构灵活的数据 | JSON原生、查询灵活 | 不适合复杂关联查询 |

**推荐：云开发MongoDB**，用于存储婚礼配置、相册等结构灵活的数据。

    url: `https://apis.map.qq.com/ws/geocoder/v1/`,

      address: keyword,
      key: QQ_MAP_KEY
    }
  })

// 距离计算
async function calculateDistance(lat1, lng1, lat2, lng2) {
  const response = await wx.request({
    url: `https://apis.map.qq.com/ws/distance/v1/`,
    data: {
      mode: 'driving',
      from: `${lat1},${lng1}`,
      to: `${lat2},${lng2}`,
      key: QQ_MAP_KEY
    }
  })
  return response.data.result.elements[0].distance
