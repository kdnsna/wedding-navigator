# 甜囍手册 P0-P3 实施审计

审计基线：`2.0.22`。本表以 v2 重构方案与当前发布门禁为准，不沿用早期功能路线中同名的 P0/P1/P2。

## P0 体验底座

| 要求 | 当前证据 | 结论 |
| --- | --- | --- |
| 宾客邀请与主人工作区状态隔离 | `stores/guest-invitation.js`、`stores/owner-workspace.js`、`stores/user.js` | 已实现 |
| 宾客六态与无邀请保护 | `idle/loading/ready/invalid/closed/offline`；无有效邀请不渲染 RSVP、分享和虚构婚书 | 已实现，待真机异常链路复验 |
| 失效主人婚书自动恢复 | `useOwnerGuard` 先同步权威工作区；账号页支持主动切换；`test-owner-workspace-recovery.js` 覆盖四类状态 | 已实现，待 2.0.22 真机复验 |
| 主包不预载主人分包 | `pages.json` 无首页 `preloadRule` | 已实现 |
| `uni.scss` 零 CSS 输出 | `check-v2-foundation.js` 编译后断言为空 | 已实现 |
| 云调用无迟到未处理超时 | `useCloud.js` 同时接住回调与 thenable，并统一超时归一 | 已实现 |
